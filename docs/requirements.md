# ふたりのバケットリスト 要件定義

## 1. 目的

恋人同士で「やりたいこと」を共有し、達成した思い出（日時・写真・メモ）を長く残せるアプリ。

## 2. 前提・制約

| 項目 | 内容 |
| --- | --- |
| 利用者 | 2人（Android 1台 + iOS 1台） |
| 利用期間 | 数年単位で使い続けられること |
| 費用 | 原則無料で運用できること |
| 配布 | ストア審査や有料の開発者登録なしで両OSに入れられること |

### 方式の決定：PWA + Firebase

| 案 | 長所 | 短所 | 判定 |
| --- | --- | --- | --- |
| ネイティブ（Kotlin + Swift） | 体験が最良 | 2本作る必要。iOS配布に年会費（Apple Developer Program）が必要 | ✕ |
| クロスプラットフォーム（Flutter 等） | 1本で両OS | iOS配布はやはり年会費 or 7日ごとの再署名 | ✕ |
| **PWA（Webアプリ＋ホーム画面に追加）** | 1本で両OS、URLを送るだけで共有、ストア不要・無料 | プッシュ通知などは一部制限あり | **◎ 採用** |

- **フロント**：React + TypeScript + Vite、PWA化（ホーム画面に追加でアプリのように起動）
- **バックエンド**：Firebase（無料の Spark プランで完結）
  - Authentication（メール＋パスワード）
  - Cloud Firestore（データと写真の保存、リアルタイム同期、オフラインキャッシュ）
- **ホスティング**：GitHub Pages（GitHub Actions で自動デプロイ）

> 写真は端末側で長辺1280pxのJPEGに圧縮して Firestore に保存します。
> Cloud Storage は新規利用に従量課金（Blaze）プランが必要になったため使いません。
> Firestore の無料枠（1GiB）で写真およそ数千枚まで保存できます。

## 3. 機能要件

### 3.1 アカウント・ペアリング
- F-01 メールアドレスとパスワードで登録／ログインできる（パスワード再設定メールも送れる）
- F-02 1人目が「ふたりのリスト」を作成すると**招待コード（6文字）**が発行される
- F-03 2人目は招待コードを入力して参加する。参加できるのは2人まで
- F-04 ログイン状態は保持され、毎回ログインし直す必要はない

### 3.2 プロフィール
- F-10 自分の**表示名**を設定・変更できる
- F-11 自分の**アイコン画像**を設定・変更できる（未設定時は名前の頭文字）
- F-12 相手のプロフィールの変更もすぐ反映される

### 3.3 やりたいこと（アイテム）
- F-20 アイテムを追加・編集・削除できる
- F-21 **「誰のやりたいこと」**を選べる：`ふたりで` / `自分` / `相手`
  - 「彼氏」「彼女」の固定ラベルではなく、各自の表示名とアイコンで表示する
- F-22 **カテゴリ**を選べる。初期カテゴリ：
  映画・ドラマ / 旅行 / 読書 / カフェ / 飲食店 / おでかけ / 体験・アクティビティ / イベント・ライブ / 買い物 / おうち / 記念日 / その他
- F-23 カテゴリは2人で自由に追加・削除できる（絵文字＋名前）
- F-24 アイテムの項目：タイトル（必須）、メモ、場所、URL、優先度（★1〜3）
- F-25 誰がいつ追加したかを記録する

### 3.4 達成記録
- F-30 アイテムを「達成」にできる
- F-31 達成時に記録できるもの：**達成日時**（初期値は現在、変更可）、**写真（複数）**、**メモ**、満足度（★1〜5）
- F-32 達成記録はあとから編集でき、写真の追加・削除もできる
- F-33 達成を取り消して未達成に戻せる

### 3.5 一覧・閲覧
- F-40 タブで切り替え：`ふたりで` / `相手` / `自分` / `すべて`
- F-41 カテゴリで絞り込める
- F-42 状態で切り替え：`未達成` / `達成済み`
- F-43 キーワード検索ができる
- F-44 並び順：新しい順 / 優先度順（達成済みは達成日の新しい順）
- F-45 達成数・達成率を表示する
- F-46 「今日なにする？」ボタンで未達成アイテムからランダムに1つ提案する
- F-47 2人の端末間でリアルタイムに同期される

## 4. 非機能要件

| ID | 内容 |
| --- | --- |
| N-01 | Android（Chrome）／iOS（Safari）でホーム画面に追加して使える |
| N-02 | スマホ縦画面に最適化。ダークモードに対応 |
| N-03 | 電波が弱いときもキャッシュで閲覧でき、操作は再接続時に同期される |
| N-04 | データは2人以外が読み書きできない（Firestore セキュリティルールで制限） |
| N-05 | 運用費0円（Firebase Spark プラン + GitHub Pages） |
| N-06 | 長期利用：データは Firebase に保存され、機種変更してもログインすれば復元される |

## 5. データ構造（Firestore）

```
users/{uid}                     … { spaceId }  自分の所属リスト
inviteCodes/{code}              … { spaceId }
spaces/{spaceId}                … { members: [uid, uid], inviteCode, categories: [...] , createdAt }
  members/{uid}                 … { displayName, avatar(小さいJPEGのdataURL) }
  items/{itemId}                … { title, owner('both' | uid), category, memo, place, url, priority,
                                    createdBy, createdAt, updatedAt,
                                    done, doneAt, doneMemo, rating, photoIds[], thumb }
  photos/{photoId}              … { itemId, data(JPEGのdataURL), createdAt }
```
